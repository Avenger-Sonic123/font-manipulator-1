# Font Manipulator — Interface

An initial interface for gesture-controlled text sizing.

**Repository created:** 2022-07-28  
**Project status:** Learning project / historical snapshot  
**Earliest recorded commit (author date):** 2022-07-27

## Features and implementation

- Instruction banner.
- Font-size placeholder.
- Visual styling and background asset.

## Technologies

HTML, CSS, JavaScript, Bootstrap, jQuery, p5.js, ml5.js.

| File | Purpose |
| --- | --- |
| [`index.html`](index.html) | Main page and user interface |
| [`main.js`](main.js) | Project-specific JavaScript |
| [`style.css`](style.css) | Page styling |

## Run or explore locally

```bash
git clone https://github.com/Avenger-Sonic123/font-manipulator-1.git
cd font-manipulator-1
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. The local server requires Python 3; browser-based dependencies may also require internet access.

Open the static interface.

## Current status and limitations

The JavaScript file is empty; pose tracking and font manipulation are not implemented.
